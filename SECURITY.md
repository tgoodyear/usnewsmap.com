# Security policy

## Reporting a vulnerability

Report it privately through GitHub: open this repository's **Security** tab and choose **Report a vulnerability**. Don't open a public issue, pull request or discussion about it.

Include what you found, the steps to reproduce it and what it affects. If you have a proof of concept, attach it to the report.

## Scope

- The site and API at `usnewsmap.com` and `api.usnewsmap.com`.
- The code, infrastructure templates and CI workflows in this repository.

Chronicling America and `loc.gov` belong to the Library of Congress; report problems with them to the Library. Please don't run load tests, denial-of-service tests or automated scanners against the live site, which runs on at most two small replicas.

## Supported versions

Only `main` and what is deployed from it get fixes.
