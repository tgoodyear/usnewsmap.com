# 10: Roadmap, Risks & Open Questions

## 10.1 Phased delivery

The plan had four phases. Where each stands on 10 November 2026:

| Phase                           | Scope                                                                                                           | State                                                                                                                                                                                                                          |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **0 Validate**                  | Spikes S-1 to S-4 (§10.2); the search engine decision                                                           | Done except the S-2 1M-page benchmark and S-4. Quickwit was chosen ([ADR-0001](adr/0001-search-engine.md))                                                                                                                     |
| **1 MVP** (parity and accuracy) | Infra, the ingest pipeline and curated lake, the Rust API, the SPA, the full backfill and index                 | Live. The served version, `pages-v20261026-1`, covers the corpus from 1736 to 1963 (about 23.8M pages, `/v1/meta`)                                                                                                             |
| **2 Public relaunch**           | Compare, first appearance, filters, export, embed, public API docs; accessibility audit, performance, load test | Partly done: the public API with its OpenAPI document (`/v1/openapi.json`) is live. 02's feature table is the list; F-09 embed and F-21 fuzzy matching aren't built. The WCAG audit and the relaunch criteria (§10.5) are open |
| **3 Research features**         | Historical boundaries, article level (American Stories), reprint clusters, semantic search                      | American Stories' text is in the index (04 §4.9) but results are still pages. The others each need their own proposal and cost check before build                                                                              |

Work the plan didn't foresee took much of the autumn: re-reading badly OCR'd pages through BOINC ([12](12-onprem-ocr-pipeline.md), [13](13-ocr-engines.md)), Congress pages (04 §4.10), and moving serving on-prem ([ADR-0027](adr/0027-onprem-serving-behind-cloudflare.md), [ADR-0029](adr/0029-onprem-primary-azure-failover.md)).

### Phase exit criteria

| Phase          | Exit criteria                                                                                                                                                                                                  |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **0 Validate** | Corpus size known within ±15%; search backend chosen from S-2 data; geocoding ≥ 98% of titles at city precision, with the rest at county precision; bulk-download rate plan agreed with LoC's published limits |
| **1 MVP**      | F-01…F-08, F-20, F-22, F-25 (state/title), F-27 shipped; counts equal a brute-force scan on the golden set; p95 targets met                                                                                    |
| **2 Relaunch** | F-09, F-21, F-23, F-24, F-26, F-28, F-29, F-30 shipped; WCAG 2.2 AA audit passed; runbooks rehearsed (full re-index, rollback)                                                                                 |
| **3 Research** | Each feature has its own proposal and cost check before build                                                                                                                                                  |

## 10.4 Open questions for the maintainer

1. **Cost.** Prod runs at about $105 a month against the $80 target (09 §9.5). The largest remaining lines are the Hot index for the spare (about $20) and the registry, monitoring and lake (about $30). Raise the ceiling, move the spare's index to Cool, or keep cutting?
2. **Branding and credits.** Keep the "US News Map" name and credit the original GTRI and eHistory team and Prof. Saunt?
3. **Domain.** Confirm control of `usnewsmap.com` (the registrar account), and whether `usnewsmap.net` (used for legacy Solr hosts) is still held.
4. **Legacy repo.** Archive `tgoodyear/usnewsmap` (not archived on 10 November 2026) with a README pointing to the new project; its exposed keys are revoked.
5. **Scope of the public API.** Anonymous-only with fair-use limits, or issue keys to researchers for higher limits?
6. **Weekly ingest.** Run a scheduled release on-prem so new LoC batches arrive without an operator (R-21)?
