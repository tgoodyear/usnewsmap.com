# Architecture Decision Records

Each record uses a lightweight [MADR](https://adr.github.io/madr/)-style format: status, context, decision, the alternatives we rejected, and consequences.

We don't edit a record's decision or reasoning after the fact. What happened afterwards goes in its header: **Amended by** names a later ADR that changed part of it, **Superseded by** one that replaced it, and **Later** says what changed and when. "Proposed; in use" means the design runs but the maintainer has not formally accepted the record.
