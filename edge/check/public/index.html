USNewsMap letter check

Machines (OCR) read these old newspapers, and they get letters wrong. You compare a printed word with two machine readings and pick the one whose letters match the print. You don't need to know the language, only to match letter shapes.

Each word goes to several people. Once 3 or more have answered and two thirds agree, it counts as checked text, which we use to measure and improve OCR for usnewsmap.com.

The box marks one word in a line. Pick a reading only if every one of its letters matches the print. Highlighted letters show where the two readings differ, but check the rest too. If neither matches, pick Neither matches, then type what the print says or copy in the closer reading and fix it. If you can't make out the letters, pick Can't tell. If the box holds no letters (a picture or a smudge), pick Not text. You only need to match letter shapes, not know the language. Add a note to tell us anything else.

    Pick Bad crop if the box shows more than one line, cuts off the word, or marks the wrong thing.
