USNewsMap letter check

Old newspapers were read by machine, and the machines get letters wrong. Here you compare one printed word with two machine readings and pick the one whose letters match the print. You don't need to know the language: you match shapes.

Each word is shown to several people. Only answers that agree become checked text, which we use to measure and train OCR for usnewsmap.com.
