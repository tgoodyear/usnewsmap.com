USNewsMap letter check

Machines (OCR) read these old newspapers, and they get letters wrong. Here you compare one printed word with two machine readings and pick the one whose letters match the print. You don't need to know the language, only to match letter shapes.

Each word goes to several people. Once it has 3 or more answers and two thirds of them agree, it becomes checked text, which we use to measure and improve OCR for usnewsmap.com.

The box marks one word in a line. Pick the reading whose letters match the printed word. Highlighted letters show where the two readings differ, but check every letter: pick a reading only if all its letters match the print, highlighted or not. If neither reading matches, pick Neither. If you can't make out the letters, pick Can't tell. If the box holds no letters (a picture or a smudge), pick Not text. You don't need to know the language, only to match shapes.
