# Test data

`dlc_zurich_ver04.tar.bz2` is a **real** Chronicling America bulk OCR archive,
downloaded unchanged from
`https://chroniclingamerica.loc.gov/data/ocr/dlc_zurich_ver04.tar.bz2`
(sha256 `ad36f7bb2ef915867460ac2b3c70f9aaa33709a9a99f554a49a9dc4fc35f3ba9`,
as listed in the collection's `datasets`). It holds one 1865 issue (4 pages,
`sn85042252`) with `ocr.txt` and ALTO `ocr.xml` per page, in LoC's current
layout. The content is from the Library of Congress's Chronicling America
collection and is in the public domain. It is used only to check that the
pipeline reads LoC's archive layout (spike S-1).
